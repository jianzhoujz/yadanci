# 牙！单词 词表

面向成人英语学习者：日常生活、职场、出行、就医、办事里用得上的词，以及四六级、雅思常见的核心词汇。
仓库根目录是基于这两份词表的背单词网页，见 [根 README](../README.md)。

| 词表 | 内容 | 对照语言 |
|---|---|---|
| [`words/`](words/) | 单词：去掉冠词后只剩一个词的条目（含 `colour / color` 这种并列变体） | 英 → 中 |
| [`phrases/`](phrases/) | 短语：搭配、短语动词、固定说法、整句，以及中文标题的发音规则条 | 英 → 中 |

两张表共用一套模块代码（`tools/sections-en.txt`），同一个模块可能两边都有条目。

## 设计原则

**按场景和词性组织，不按字母或词频。** 模块按用途分：邮件语块、口语应答、图表描述、
职场、住房、健康、银行消费、交通、教育、消费者服务、政府社区、科技、环境、
日常生活，核心动词、形容词、名词、副词与连接词，社会、科学、经济、自然、心理、
法律、艺术、媒体等话题词，以及拼写、英美差异、易混词、发音。

**功能语块优先。** 写邮件、日常应答，得体与否靠完整语块和语域，不是生僻词。
所以短语表里大量条目是整句，标记为 `chunk`，要整条背。

**英美差异单列。** `UKUS` 模块对照英式与美式拼写（`colour` / `color`、`centre` / `center`），
用法要点里也会注明英美说法的不同。

**收录的不只是词。** `SOUND` 模块收重音位置、静音字母、-ed 读法、弱读与意群停顿。

**每条都带用法要点。** `note` 列写的是搭配限制、语域、易错点、英美差异。
这一列比中文释义更重要——错的往往不是词义，是用法。

## 每个目录里有什么

```
<deck>/
  _src.psv                 数据源，| 分隔，唯一需要手动编辑的文件
  <deck>-vocab.tsv          制表符分隔，导入 Anki / Excel / Quizlet
  <deck>-vocab.md           按模块分组的阅读版，适合通读和打印
```

## 修改与重新生成

编辑 `_src.psv`，然后在**仓库根目录**跑：

```bash
bash vocab/tools/build.sh
```

`.tsv` 和 `.md` 都是生成产物，不要直接改。
